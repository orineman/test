Upgrade your Laplink Everywhere Host

The latest version of the Laplink Everywhere Host application is "Laplink Everywhere, v3.0".  You can check the version that you have by right-clicking on the Laplink Everywhere icon in your Windows task tray and selecting "About Laplink Everywhere".

To upgrade your Laplink Everywhere Host application:

  1. If the Laplink Everywhere Host application is currently running on your computer (indicated by a Laplink Everywhere icon in the Windows task tray), close Laplink Everywhere by right-clicking on the Laplink Everywhere icon and choosing "Exit".


  2. Click here to download the newest Laplink Everywhere Host application.


  3. Select "Open" or "Run" when prompted by the "file download" dialog box.


  4. Complete the installation once the download is complete.


  5. The new Laplink Everywhere Host application will automatically start.

Note:  After the upgrade, if you do not see the Laplink Everywhere icon in your Windows task tray you can manually restart Laplink Everywhere by selecting "Laplink Everywhere" from the "Laplink Everywhere" program group located in your Windows start menu.
