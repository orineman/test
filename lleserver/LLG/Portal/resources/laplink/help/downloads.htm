Click here to download the Laplink Everywhere Host application (English version: "Laplink Everywhere, v3.0").

Note: You should install the Laplink Everywhere Host application on the computer that you wish to remotely access.  This is the computer that contains your files and Outlook data that you want to remotely access while you are away from that computer. You DO NOT need to install the Laplink Everywhere Host application on the computer(s) you use to remotely access from.
