Download Symmetry Live Desktop

Click here to download the Symmetry Live Desktop application (English version: "Symmetry Live, v1.0").

Note: You should install the Symmetry Live Desktop application on the computer that you wish to remotely access.  This is the computer that contains your files and Outlook data that you want to remotely access while you are away from that computer. You DO NOT need to install the Symmetry Live Desktop application on the computer(s) you use to remotely access from. On those computers you only need to open the Symmetry Live user website (https://symmetrylive.com) in a web browser (e.g. Internet Explorer).
