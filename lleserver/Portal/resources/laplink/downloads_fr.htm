Télécharger l'hôte Laplink Everywhere

Cliquez ici pour télécharger l'application hôte Laplink Everywhere (version anglaise : "Laplink Everywhere, v3.0").

Remarque : vous devez installer l'application hôte Laplink Everywhere sur l'ordinateur auquel vous souhaitez pouvoir accéder à distance. Il s'agit de l'ordinateur contenant vos fichiers et les données Outlook auxquelles vous souhaitez pouvoir accéder à distance lorsque vous n'avez pas votre ordinateur sous la main. Il est INUTILE d'installer l'application hôte Laplink Everywhere sur le ou les ordinateurs que vous utilisez pour vous connecter à distance. Sur ces ordinateurs, vous devez simplement ouvrir le site Web utilisateur Laplink Everywhere (https://www.ll2go.com) dans un navigateur (Internet Explorer, par ex.).
