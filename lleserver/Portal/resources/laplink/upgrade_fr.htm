Mise à jour de Laplink Everywhere 2.0

Si Laplink Everywhere 2.0 a déjà été installé sur votre ordinateur, vous DEVEZ suivre les étapes de mises à jour présentées ci-dessous;

Cliquez ici et enregistrez-vous avec votre nom d'utilisateur ou votre mot de passe Laplink Everywhere 2.0.  Vous devez suivre les étapes indiquées pour mettre à jour votre compte et affecter votre ordinateur au nouveau système AVANT d'installer le logiciel Laplink Everywhere 4.0.

Si vous ne vous souvenez plus des identifiants de votre compte, suivez la procédure indiquée ici.  Cliquez ensuite ici pour télécharger l'application hôte Laplink Everywhere (version anglaise : "Laplink Everywhere, v3.0") et procédez normalement à son installation.

Remarque : vous devez installer l'application hôte Laplink Everywhere sur l'ordinateur auquel vous souhaitez pouvoir accéder à distance.  Il s'agit de l'ordinateur contenant vos fichiers et les données Outlook auxquelles vous souhaitez pouvoir accéder à distance lorsque vous n'avez pas votre ordinateur sous la main. Il est INUTILE d'installer l'application hôte Laplink Everywhere sur le ou les ordinateurs que vous utilisez pour vous connecter à distance. Sur ces ordinateurs, vous devez simplement ouvrir le site Web utilisateur Laplink Everywhere (https://www.ll2go.com) dans un navigateur (Internet Explorer, par ex.).
