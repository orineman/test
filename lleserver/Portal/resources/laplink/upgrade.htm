Upgrading from Laplink Everywhere 2.0

If you ever had Laplink Everywhere 2.0 installed on your computer you MUST properly perform the upgrade steps outlined below;

Click here and sign in with your Laplink Everywhere 2.0 user name or password.  You must follow the steps listed to upgrade you account and assign your computer to the new system BEFORE installing the Laplink Everywhere 3.0 software

If you can not remember your account perform the steps outlink here.  Then click here to download the Laplink Everywhere Host application (English version: "Laplink Everywhere, v3.0") and install normally.

Note: You should install the Laplink Everywhere Host application on the computer that you wish to remotely access.  This is the computer that contains your files and Outlook data that you want to remotely access while you are away from that computer. You DO NOT need to install the Laplink Everywhere Host application on the computer(s) you use to remotely access from. On those computers you only need to open the Laplink Everywhere user website (https://www.ll2go.com) in a web browser (e.g. Internet Explorer).
