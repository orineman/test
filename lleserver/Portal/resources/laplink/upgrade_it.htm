Aggiornamento da Laplink Everywhere 2.0

Se sul computer Laplink Everywhere 2.0 è stato installato in passato, è NECESSARIO eseguire correttamente la procedura di aggiornamento indicata di seguito;

Fare clic qui e accedere tramite il proprio nome utente e password Laplink Everywhere 2.0.  Seguire la procedura indicata per aggiornare l’account e assegnare il computer al nuovo sistema PRIMA di installare Laplink Everywhere 3.0

Se non si ricordano le informazioni relative al proprio account, eseguire la procedura indicata qui..  Quindi fare clic qui per scaricare l'applicazione Laplink Everywhere Host (versione inglese: ""Laplink Everywhere, v3.0") e procedere normalmente all'installazione.

Nota: è consigliabile installare l'applicazione Laplink Everywhere Host sui computer ai quali si desidera accedere da remoto.  Si tratta del computer sul quale si trovano i file e i dati di Outlook ai quali si desidera accedere da remoto. Non è necessario installare l'applicazione Laplink Everywhere Host sui computer utilizzati per l'accesso da remoto. Su questi computer è sufficiente aprire il sito Web utente di Laplink Everywhere (https://www.ll2go.com) in un browser Web (es. Internet Explorer).
