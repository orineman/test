Laden Sie den Laplink Everywhere Host herunter

Klicken Sie hier um die Laplink Everywhere Hostanwendung herunterzuladen (Deutsche version: "Laplink Everywhere, v4.0").

Hinweis: Sie sollten die Laplink Everywhere Hostanwendung auf dem Computer installieren, auf den Sie über das Internet zugreifen möchten.  Dies ist der Computer, der Ihre Dateien und Outlook-Daten enthält, auf die Sie zugreifen möchten, während Sie sich unterwegs befinden. Sie müssen die Laplink Everywhere Hostanwendung NICHT auf den Computer installieren, von dem Sie aus der Ferne zugreifen möchten. Auf diesen Computern müssen Sie nur die Laplink Everywhere Benutzer-Webseite (https://www.ll2go.com) in einem Web-Browser (z.B. Internet Explorer) öffnen.
